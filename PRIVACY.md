**Privacy Policy**

Smpl New Tab does not collect, transmit, sell, or share any personal information.

The extension stores only non-personal settings (selected theme and clock visualization). These preferences are saved using the browser’s built-in storage API and may sync across the user’s own devices if the browser’s sync feature is enabled. If sync is not available, settings are stored locally in the browser. No data is sent to or stored on any third-party or developer-controlled servers.
